# MealBridge · 一起吃，不必將就

> A constraint-first group meal decision room, with explainable fairness and versioned menu evidence.

為「幾位同學想一起吃午餐，但有人吃素、有人預算有限」設計的手機優先網頁 App。不是另一個餐廳星等排行榜：先確定**同一間店有每個人都能接受的實際餐點**，再比較選擇。

這是全新、AI 協作開發的作品集 v1.1，不是舊課程專案原始碼的還原；未有真實使用者研究或營運成效。所有內建店家、價格與座標均為原創虛構示範。

## v1.1：附近探索 × 共同決策

- **定位與範圍**：按鈕觸發瀏覽器定位，或手選公共集合點／輸入座標；100 公尺至 5 公里，依 Haversine 直線距離過濾。不是導航、步行時間或持續追蹤。
- **來源不混淆**：虛構菜單可示範全員決策；另外同意後，可查詢 OpenStreetMap 真實店家。沒有已查核菜單的真實店家，不會被當成符合預算與飲食的推薦。
- **共同集合點**：主辦明確同意後才分享座標／半徑；每人可設最遠距離。修改集合點會使舊比較失效；可更新邀請碼撤銷舊連結。
- **重新設計 UI**：米白／陶土色、餐廳列表＋距離示意、獨立共餐工作區與菜單來源簿。不再沿用運動專案的卡片布局。設計證據與取捨見 [UIUX.md](UIUX.md)。

本版未完成實際瀏覽器桌機／手機視覺驗收與實機 GPS 驗收；自動測試不等於真機測試。[舊版截圖](screenshot.jpg) 僅記錄 v1.0，不代表此版 UI。

## 為什麼值得做

搜尋餐廳容易，協調每位同行者的限制不容易。單一預算標籤或平均分數會掩蓋少數人的不可接受選項。本案以共享決策室收集條件，明確回覆「能一起吃什麼」及「哪些店為什麼不行」。

適合小群體已有候選菜單、需要一起決定；若要探索大量真實餐廳、訂位或導航，既有服務更完整。競品與開源調查、差異的證據及限制見 [PRODUCT.md](PRODUCT.md)。

## 已完成

- 帳號註冊、登入、登出，8 小時 HttpOnly 工作階段；隱私決策室及不可猜測邀請碼。
- 每人餐費上限、蛋奶素、不吃牛／豬／辣、離共同集合點的距離上限；未知成分在相關限制下不視為安全符合。
- 菜單超過 30 天或日期在未來則排除；每位成員都須填妥才能比較。
- 硬條件過濾後，以最低個人分數優先、平均分數次之排序；逐人餐點、餘額及排除理由可解釋。
- 主辦人定案時同時檢查決策室與菜單版本，避免用舊結果定案；保存不可變更決策快照，可下載 JSON。
- 維護金鑰保護的菜單整批驗證匯入；登入成員可回報錯誤，回報不會自動竄改菜單。
- 響應式介面、PWA manifest、192/512 圖示及只快取公開介面的 service worker；離線不假裝送出操作。

## 本機啟動

Python 3.11–3.13。無需 Node、付費金鑰或外部資料庫即可啟動。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.lock.txt
.venv\Scripts\python seed.py
.venv\Scripts\python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

macOS / Linux 將 `.venv\Scripts\python` 改為 `.venv/bin/python`。開啟 <http://127.0.0.1:8000>，自行註冊示範用帳號，不要重用真實密碼。API 文件：`/docs`。

`seed.py` 只匯入五間虛構餐廳，不會建立預設管理員或密碼；已有菜單時拒絕覆蓋，明確加 `--replace` 才取代。查核日期是測試基準，不是實地驗證。

環境變數（由系統設定，程式不自動載入 `.env`）：

| 名稱 | 用途 |
|---|---|
| `MEALBRIDGE_DB` | SQLite 檔案路徑，預設 `data/mealbridge.db` |
| `CATALOG_KEY` | 選用，菜單維護金鑰；未設定則遠端匯入停用 |
| `COOKIE_SECURE` | HTTPS 服務設為 `1`；本機 HTTP 保持 `0` |

正式菜單須自行取得合法資料、人工查核飲食分類及標明來源，再使用 `/api/catalog` 置換。沒有爬取未授權網站；真實店家探索使用公開 Overpass API，不補造價格、營業狀態、評分或飲食分類。

### 定位與外部服務怎麼使用

1. 「附近探索」→ 地點 →「使用我的目前位置」，瀏覽器會詢問權限；拒絕／逾時可選示範區或手動輸入座標。正式部署需 HTTPS，本機 localhost 可測試。瀏覽器可能使用 GPS、Wi-Fi 或其他來源，不保證衛星 GPS 精度。
2. 選 100／500／1000／3000／5000 公尺範圍。示範店家固定在台北示範區，不會被搬到你的定位附近。
3. 要找真實店家，點「真實 OSM 店家」，閱讀同意說明後載入。伺服器把中心約略化到 0.01 度格網，向固定的 `overpass-api.de` 送出擴大範圍查詢，再依原選點過濾距離。
4. 距離示意不是街道圖；另行同意才載入 OSM 街道圖，只顯示約略區域，不標示私人定位點。OSM 有自己的資料／網路位址處理方式，並非完全匿名。

GPS 結果只保留在本次頁面記憶體，座標用 POST body 查詢、不放 URL 或離線快取；**伺服器仍會接收搜尋座標**以計算距離，不是端對端加密。未主動分享不會寫入決策室。使用者同意分享的共同點則會保存，成員可看；請優先使用公共集合點。

公開 Overpass 不是有 SLA 的商用搜尋服務。全站預算 80 次／24 小時、每來源 20 次／小時；查詢最多取擴大範圍前 80 筆再過濾，不保證附近清單完整。2026-10-17 實際外連遇到上游錯誤，**尚未驗證成功取得即時店家**；失敗明確顯示 503，不以示範店家冒充。解析、同意與失敗行為已有模擬測試。

## 三分鐘展示

1. A、B 使用不同瀏覽器工作階段登入；A 在附近探索選台北示範區、範圍 1 公里，建立「週五午餐」並勾選同意分享集合點，再分享邀請。
2. A 設 NT$140、台式；B 加入並設 NT$120、蛋奶素、不吃辣。
3. 比較：青禾食堂與小巷麵屋可行；辣日沒有 B 可吃的餐點，昨日小館資料過期，未明料理資訊不足。
4. 先比較、再修改一人的偏好；舊版本定案會被 API 拒絕，重新比較才能定案。
5. 主辦人選定並匯出快照。菜單日後改價，不會改寫這次的決策紀錄。

## 驗證

```powershell
.venv\Scripts\python -m pip install -r requirements-dev.lock.txt
.venv\Scripts\python -m pytest -q
node --check app.js
node --check geolocation.js
npm ci --ignore-scripts --no-audit --no-fund
npm test
```

Node 22+ 僅用於測試，不影響無前端建置的啟動方式。v1.1 本機 **61 項 Python + 17 項 Node 測試**通過：原有決策／授權／快照，加上距離邊界、舊資料庫升級、分享版本衝突、邀請撤銷、外部同意／上游失敗、位置約略化、查詢配額、定位成功／拒絕／逾時與 PWA 快取。LinkeDOM + 模擬 API 驗證頁面事件、來源同意、範圍提交、登出及過期請求不還原私人資料；不是實際瀏覽器端到端或視覺測試。CI 設定 Windows / Ubuntu × Python 3.11 / 3.12 / 3.13；實際遠端結果以 [Actions](https://github.com/Ct2510/MealBridge/actions) 為準。

## 架構與邊界

FastAPI + Pydantic + SQLite + 原生 JavaScript / CSS。刻意不加入不必要的前端建置鏈，保留可讀的決策演算法與完整交易。詳見 [ARCHITECTURE.md](ARCHITECTURE.md)、[API.md](API.md)。

PWA 可安裝性取決於 HTTPS、瀏覽器及平台；iPhone 通常由分享選單加入主畫面。只有介面可離線，個人偏好、登入回應與決策 API 不會快取。未提供背景同步或推播。

這不是訂位、支付、導航、過敏原檢測或醫療飲食工具。蛋奶素不等於全素，肉類清單不等於完整成分表。正式對外服務前仍須補齊資料查核流程、帳號復原／刪除、監控、備份還原演練、負載與資安審查。附 Dockerfile，但本機未驗證容器建置。
